### 🥽 About & Focus Area

I am a **Creative XR Developer** passionate about turning web browsers into immersive 3D spatial playgrounds. Currently building bare-hand gesture WebXR experiences on Meta Quest 3S, computer vision AR games, and motion-reactive floor projections.

- 🔭 **Currently Building**: [XR Slingshot VR](https://github.com/AmarGore47/Vr_Game) - Controller-free hand-tracking Angry Birds VR game for Meta Quest 3S.
- 🎯 **Core Tech**: WebXR, Three.js, A-Frame, MediaPipe, WebGL, TypeScript, React.
- 💬 **Ask Me About**: Spatial Computing, 3D Web Audio Synthesis, WebGL Shaders & AR/VR.
